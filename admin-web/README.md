# LegalBot Admin Panel

Panel de administración para LegalBot con dashboard y gestión de usuarios.

## 🚀 Instalación

No requiere instalación. Solo abrir en navegador.

## ⚙️ Configuración

1. Asegurar que el backend esté corriendo en `http://localhost:3000`
2. Configurar base de datos PostgreSQL
3. Crear usuario admin en la BD

## ��‍♂️ Ejecutar

Abrir `login.html` en el navegador.
